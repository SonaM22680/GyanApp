# 📚 ज्ञान ऐप (Gyan App)

हिंदी + English में बना एक **मोबाइल-फ्रेंडली लर्निंग ऐप** — क्विज़, मॉक टेस्ट, Ludo गेम और 3D-प्रिंट ड्रोन डिज़ाइन लैब, सब एक ही जगह। पूरा ऐप सिर्फ़ **एक `index.html` फ़ाइल** में है, कोई इंस्टॉलेशन या बिल्ड की ज़रूरत नहीं।

🔗 **Live Demo:** [https://sonam22680.github.io/GyanApp/](https://sonam22680.github.io/GyanApp/)

> A bilingual (Hindi/English), mobile-first learning app: quizzes, mock exams, Ludo, and a drone Design Lab with STL export — all in a single HTML file.

---

## ✨ फ़ीचर्स (Features)

### 📝 क्विज़ (Quiz)
- 12 विषय: इतिहास, भूगोल, हिंदी, English, रिजनिंग, गणित, संविधान, विज्ञान, सामान्य ज्ञान, कंप्यूटर (ICT), बाल सुरक्षा कानून, छात्रावास प्रशासन
- **रिजनिंग** टॉपिक: सीटिंग अरेंजमेंट, सादृश्य, रक्त संबंध, कोडिंग-डिकोडिंग, श्रृंखला, कथन-निष्कर्ष आदि
- **गणित** टॉपिक: प्रतिशत, अनुपात, लाभ-हानि, ब्याज, समय-चाल-दूरी, समय और कार्य, नल-टंकी आदि
- **कंप्यूटर** टॉपिक: इनपुट/आउटपुट, मेमोरी, ऑपरेटिंग सिस्टम, नेटवर्क, संख्या प्रणाली आदि
- हर सवाल पर **40 सेकंड का टाइमर**, स्किप का विकल्प और अंत में स्कोर
- संविधान और इतिहास के **नोट्स**

### 🏆 परीक्षा / मॉक टेस्ट (Exam)
- SSC CGL, रेलवे, बैंक, UP पुलिस कांस्टेबल, UP SI, UP TET के मॉक पेपर
- पेपर टाइमर, सवाल सूची, उत्तर हटाना/छोड़ना, सबमिट और रिव्यू
- सही / गलत / छोड़े गए सवालों के साथ पूरा रिज़ल्ट
- 🔜 *मासिक इनाम परीक्षा (सिर्फ़ 18+, मुफ़्त एंट्री)* — जल्द आ रही है

### 🎮 गेम्स (Games)
- 🎲 **Ludo** — एक फ़ोन पर 2 या 4 खिलाड़ी (ऑफ़लाइन)
- 🌐 दोस्तों के साथ **ऑनलाइन Ludo** (रूम कोड से) — Firebase Realtime Database जोड़ने पर चालू होता है ([नीचे देखें](#-ऑनलाइन-ludo-चालू-करें))

### 🛠️ डिज़ाइन लैब (Design Lab)
छोटा ड्रोन डिज़ाइन करें और 3D प्रिंट करें:
- मल्टी-रोटर, टैंडम हेली, मेन+टेल हेली लेआउट
- हाथों की संख्या (2/3/4/6), मोटर, बैटरी, प्रिंट मटेरियल का चुनाव
- हाथ की लंबाई/चौड़ाई/मोटाई, सेंटर प्लेट, FC माउंट के स्लाइडर
- लाइव 3D प्रीव्यू (घुमा सकते हैं) और **उड़ान का अंदाज़ा**
- अपने नाप से कैमरा पॉड, बैटरी ट्रे और लैंडिंग स्किड बनाना
- **पार्ट्स लिस्ट (BOM)** — वज़न और अनुमानित कीमत (₹) के साथ
- 🤖 ऑटो-ऑप्टिमाइज़ (सबसे लंबी उड़ान वाला डिज़ाइन) और प्रॉप के हिसाब से ऑटो-फिट
- 🏆 स्कोर बोर्ड (आपके फ़ोन में सेव होता है)
- ⬇️ **STL डाउनलोड** — सीधे स्लाइसर में खोलकर प्रिंट करें

### 🎨 और भी
- हिंदी ⇄ English एक टैप में बदलें
- 🌗 Light / Dark मोड अपने आप (फ़ोन की सेटिंग के अनुसार)
- सुरक्षित-क्षेत्र (safe-area) सपोर्ट के साथ मोबाइल UI और नीचे नेविगेशन बार
- बैक बटन सपोर्ट (ब्राउज़र history के साथ)

## 🚀 चलाएँ (Run Locally)

1. रिपॉज़िटरी क्लोन करें:
   ```bash
   git clone https://github.com/SonaM22680/GyanApp.git
   cd GyanApp
   ```
2. `index.html` को किसी भी ब्राउज़र में खोलें — बस इतना ही!

या एक लोकल सर्वर चलाएँ:
```bash
python3 -m http.server 8000
# फिर ब्राउज़र में खोलें: http://localhost:8000
```

## 🌐 ऑनलाइन Ludo चालू करें

ऑनलाइन मोड के लिए `index.html` में Firebase Realtime Database का URL डालना होगा:

1. [Firebase Console](https://console.firebase.google.com) में प्रोजेक्ट बनाएँ और **Realtime Database** चालू करें
2. `index.html` में यह लाइन खोजें:
   ```js
   FIREBASE_DB_URL=""
   ```
3. अपना URL डालें:
   ```js
   FIREBASE_DB_URL="https://your-project-default-rtdb.firebaseio.com"
   ```
4. Database के Rules में `ludo` नोड के लिए read/write की अनुमति दें

> 🔒 सावधानी: सार्वजनिक रूप से खुले Rules सिर्फ़ टेस्टिंग के लिए ठीक हैं। असली इस्तेमाल से पहले Rules सख़्त करें।
