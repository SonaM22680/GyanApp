# 📚 Gyan App | ज्ञान ऐप

> सरकारी परीक्षाओं की तैयारी के लिए एक हल्का, **सिंगल-फ़ाइल** हिंदी/English क्विज़ ऐप।
> A lightweight, single-file Hindi/English quiz app for government exam preparation.

कोई install नहीं, कोई build नहीं, कोई server नहीं। बस `index.html` खोलिए और शुरू कीजिए।

---

## ✨ Features

| Tab | क्या मिलता है |
|---|---|
| 📝 **Quiz** | 12 विषयों में **1300+ सवाल**, टॉपिक-वार क्विज़, मॉक टेस्ट, SSC/EMRS फ़ुल पेपर और संविधान नोट्स |
| 🏆 **Exam** | इनाम वाली मासिक परीक्षा की शर्तें और सहमति (परीक्षा जल्द शुरू होगी) |
| 🎮 **Games** | Ludo: 2 या 4 खिलाड़ी, एक फ़ोन पर (ऑफ़लाइन) या दोस्तों के साथ ऑनलाइन (Firebase से) |
| 🛠️ **Design Lab** | जल्द आ रहा है |
| 💬 **Chat** | डेमो चैट, गाली और निजी जानकारी का ऑटो-फ़िल्टर, Report और Block के साथ |

### 📝 Quiz टैब

**विषय:** इतिहास, भूगोल, हिंदी, English, रिजनिंग, गणित, संविधान, विज्ञान, सामान्य ज्ञान, कंप्यूटर (ICT), बाल सुरक्षा कानून, छात्रावास प्रशासन

- हर क्विज़ में **10 सवाल**, हर सवाल के लिए **40 सेकंड**
- सही उत्तर: **+1**, गलत उत्तर: **−0.25**, छोड़ने पर कोई कटौती नहीं
- हर सवाल के बाद **व्याख्या (explanation)**
- हर बार विकल्पों का क्रम बदलता है (shuffle)
- **रिजनिंग** (8 टॉपिक) और **कंप्यूटर/ICT** (7 टॉपिक) के लिए टॉपिक-वार क्विज़, ICT में डायग्राम भी

### 🎯 मॉक टेस्ट

**छोटे मॉक (25 सवाल):** SSC CGL, रेलवे, बैंक, UP पुलिस कांस्टेबल, UP SI (UP TET जल्द)

**फ़ुल पेपर** (असली परीक्षा जैसा टाइमर, आगे-पीछे जाना, सवाल पैलेट और सबमिट से पहले पुष्टि):

| पेपर | सवाल | समय | अंकन (सही / गलत) |
|---|---|---|---|
| SSC CGL Tier-1 | 100 | 60 मिनट | +2 / −0.5 |
| SSC CGL Tier-2 (Paper-1) | 130 | 135 मिनट | +3 / −1 |
| EMRS छात्रावास अधीक्षक (5 सेट) | 60 | 90 मिनट | +1 / −0.25 |

नतीजे में कुल स्कोर, सेक्शन-वार अंक, लगा समय और हर सवाल की सही/गलत समीक्षा (व्याख्या के साथ) मिलती है।

### 📖 संविधान नोट्स

कॉपी-स्टाइल हाथ-लिखे लुक में **21 नोट्स**: संविधान सभा का गठन, संविधान निर्माण, सामान्य परिचय, अनुसूचियाँ, विशेषताएँ, स्रोत, संशोधन, प्रस्तावना, मौलिक कर्तव्य, नीति निदेशक तत्व, लोकनीति, राष्ट्रपति, प्रधानमंत्री, केंद्रीय मंत्रीपरिषद, राज्यपाल, मुख्यमंत्री, राज्य मंत्रीपरिषद, राज्य विधानमंडल, विधानसभा, नगरीय स्वशासन, संभाग व जिला प्रशासन।

## 🚀 Quick Start

### Local चलाने के लिए
```bash
git clone https://github.com/SonaM22680/GyanApp.git
cd GyanApp
# index.html को किसी भी browser में खोलें
```

या कोई भी static server:
```bash
python3 -m http.server 8000
# फिर http://localhost:8000 खोलें
```

### GitHub Pages पर मुफ़्त hosting
1. फ़ाइल का नाम `index.html` रखें और repo में push करें
2. Repo को **Public** करें (Free account में Pages के लिए ज़रूरी है)
3. **Settings → Pages**
4. **Source:** `Deploy from a branch` → `main` → `/ (root)` → **Save**
5. कुछ मिनट बाद ऐप यहाँ चलेगा: `https://sonam22680.github.io/GyanApp/`

## 🧩 नए सवाल कैसे जोड़ें

सारे सवाल `index.html` के अंदर ही हैं। `//@@BANK_START` और `//@@BANK_END` के बीच यह फ़ॉर्मेट इस्तेमाल करें:

```js
A('history', 'इतिहास', [
  ['सवाल यहाँ लिखें', 'विकल्प1;विकल्प2;विकल्प3;विकल्प4', 0, 'व्याख्या यहाँ लिखें'],
  //                                                       ↑ सही उत्तर का नंबर (0 से शुरू)
]);
```

**श्रेणी के कोड (category):** `history`, `geography`, `hindi`, `english`, `reason`, `math`, `samvidhan`, `science`, `gk`, `ict`, `child`, `admin`

**English अनुवाद:** `ENX` सूची के अंत में इस फ़ॉर्मेट में जोड़ें (हिंदी सवालों के क्रम में):
```
"English question|opt1;opt2;opt3;opt4|English explanation"
```

**नया टैब/सेक्शन:** `MODULES` array में एक entry जोड़ें।

## 🎮 Ludo: ऑनलाइन मोड चालू करना

ऑफ़लाइन मोड सीधे चलता है। ऑनलाइन खेलने के लिए Firebase Realtime Database चाहिए:

1. [Firebase Console](https://console.firebase.google.com/) में प्रोजेक्ट बनाएँ और **Realtime Database** चालू करें
2. `index.html` में यह लाइन खोजें:
   ```js
   var FIREBASE_DB_URL="";
   ```
3. अपना URL डालें:
   ```js
   var FIREBASE_DB_URL="https://your-project-default-rtdb.firebaseio.com";
   ```
4. Database के **Rules** अपनी ज़रूरत के हिसाब से सेट करें

> ⚠️ **ध्यान दें:** Rules खुले छोड़ने से कोई भी डेटा पढ़/लिख सकता है। Public उपयोग से पहले सही सुरक्षा नियम लगाएँ।
